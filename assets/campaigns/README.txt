Dungeons & Dolphins campaign packs

Campaign content is loaded only when Adventure mode opens. Each campaign remains a separate data file so the character tracker and catalogs do not consume additional runtime heap.

The bundled reef_wardens pack demonstrates scenes, choices, skill checks, success and failure branches, inventory rewards, quest flags, achievements, milestones, procedural sprite tags, and per-character checkpoints.

Copy a modified pack to /ext/apps_data/dungeons_and_dolphins/campaigns/reef_wardens/scenes.txt to override the bundled file.
