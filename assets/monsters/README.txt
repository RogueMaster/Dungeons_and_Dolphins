MONSTER PACK FORMAT

The bundled index contains freely licensed reference records. Each index row is:
id|name|challenge rating in eighths|XP|AC|HP|type|environment

Examples: CR 1/4 is 2, CR 1/2 is 4, CR 1 is 8, and CR 10 is 80.
Place optional user records in apps_data/dungeons_and_dolphins/monsters/index.txt
and matching key/value blocks in monsters/statblocks/{id}.txt.

The app scans the index on demand and opens only one stat block at a time.
